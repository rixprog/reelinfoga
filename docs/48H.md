# 48-Hour Execution Plan

The plan is ruthless about one thing: **the pipeline is the product.** UI polish is worth
less than a reel whose location was found in the comments. Build the spine first, make
it pretty last, and cut features from the middle.

**Non-negotiable rule: seed data by Hour 6.** If you're still fighting Instagram scraping
at Hour 20, the demo dies. Get 25 reels cached to disk early, then build against the
cache.

---

## Hour 0–4 · Skeleton and spine

| | |
|---|---|
| **Goal** | A URL goes in one end, a row comes out the other. Nothing intelligent yet. |

- `docker-compose.yml`: Postgres (postgis + pgvector), Redis
- Apply [SCHEMA.sql](SCHEMA.sql)
- FastAPI: `POST /api/ingest {url}` → insert `reels` row (status `queued`) → enqueue Celery
- Celery worker: `yt-dlp` → mp4 + caption + metadata → `raw_payload`, status `ready`
- Next.js: paste-URL box + a feed that polls `/api/reels`

**Exit check:** paste a reel URL, see the thumbnail and caption appear in the feed.

> If yt-dlp needs cookies for Instagram, export them now and move on. Don't rabbit-hole.

---

## Hour 4–8 · Seed the demo set (do not skip)

| | |
|---|---|
| **Goal** | 25 food reels cached to disk as complete JSON payloads. |

- Hand-pick reels across Malayalam / Tamil / Hindi and across difficulty:
  - 8 **easy** — place name spoken clearly or in the caption
  - 8 **medium** — name only in on-screen text
  - **6 hard — location ONLY in the comments** ← the money shot, get these right
  - 3 **negative** — food reels with no identifiable place (tests the null path)
- Write `scripts/seed.py`: for each, fetch video + caption + comments → `seed/<id>.json`
- Add `--from-seed` to the ingest worker so the whole pipeline can run offline

**Exit check:** `python scripts/seed.py` runs clean and `seed/` has 25 JSON files.
From here on, **you never need Instagram to be up.**

---

## Hour 8–14 · Transcription + romanization

- ffmpeg: video → 16kHz mono wav; video → 6–8 keyframes (scene-change detection)
- `transcribe(audio) -> {native, english, lang}` behind one interface
  - Sarvam speech-to-text-translate as the impl
  - Whisper `large-v3` as the fallback impl (same signature)
- Transliteration → `transcript_roman` (Sarvam transliterate, or `indic-transliteration`)
- Build `search_text` = `transcript_en + caption + hashtags`
- Show all three transcripts on the reel detail page — the language-switcher UI is a
  30-minute build and it's one of the strongest visual proofs in the demo

**Exit check:** a Malayalam reel shows Malayalam, English, and Manglish side by side.

---

## Hour 14–22 · Extraction — the core

This is the longest block because it's where the product lives. Budget the time.

- Comment prefilter: multi-script location-intent regex + parent/child pairing
- Comment ranking: creator replies first, then likes
- Build the evidence block (frames + transcripts + caption + hashtags + ranked comments)
- Claude Opus 5 call with `output_config.format` and the `FoodSpot` JSON schema
- Persist to `extractions`
- **Iterate the prompt against all 25 seeded reels.** Write
  `scripts/eval.py` that runs the whole seed set and prints a table:
  `id | expected_place | extracted_place | confidence | source`.
  You will run this thirty times. Make it fast and make the output readable.

**Exit check:** ≥20 of 25 reels extract the correct place name, and **all 6 comment-only
reels resolve with `source: creator_reply` or `comment`.** If the comment-only cases
fail, fix them before doing anything else — they are the differentiator.

---

## Hour 22–28 · Places resolution + map

- Google Places Text Search; upsert into `places` by `google_place_id`
- Name-similarity scoring → HIGH / MEDIUM / LOW tiering
- Write `reel_places` with `resolved_from` and `evidence_quote`
- Map view (Mapbox GL or Leaflet + OSM tiles) with clustered pins
- Pin popup: place name, rating, saved reel count, "Directions" deep link

**Exit check:** the map shows pins in the right cities, and clicking one shows the reels.

---

## Hour 28–34 · Search

- Voyage embeddings on `search_text` → `reels.embedding`
- Hybrid RRF query (the SQL is already written in [SCHEMA.sql](SCHEMA.sql))
- Search UI with category chips and a city filter
- Test the demo queries explicitly:
  - *"that spicy beef place near the beach"* (semantic)
  - *"kozhikode biryani"* (keyword)
  - *"nalla thattukada"* (Manglish → trigram arm)

**Exit check:** all three query styles return the right reel in the top 3.

---

## Hour 34–40 · Location features + confirm cards

- `/api/nearby` with `ST_DWithin`
- "Near Me" screen: `watchPosition`, distance-sorted list + map
- **Location simulator**: a dev drawer that sets a fake position. This is how you demo.
- Foreground proximity notification at 500m, deduped via `proximity_alerts`
- Confirm card for MEDIUM: *"Is this the place?"* + candidates + the evidence quote →
  writes `confirmed_by_user`

**Exit check:** simulate a walk down a Kozhikode street → notification fires once.

---

## Hour 40–46 · Polish and the story

- Ingest progress UI — show the pipeline stages live (`fetching → transcribing →
  extracting → resolving`). Watching the stages tick is far more convincing than a
  spinner, and it makes the 30-second processing time feel like capability instead of lag.
- **Evidence panel** on the reel detail page: *"Found via creator reply: 'Al Faham,
  Palayam — near the bus stand'"* with the quote. Highest impact-per-minute in the build.
- Dark mode, empty states, loading skeletons
- Deck: problem → the comment-mining insight → live demo → the six-vertical slide

---

## Hour 46–48 · Rehearse

Freeze the code. Run the demo **five times**. Find the thing that breaks on run three.

---

## Demo script (6 minutes)

| Time | Beat |
|---|---|
| 0:00 | *"I save 40 food reels a month. I've been back to two of them."* Open Instagram, scroll saved reels. The problem is visceral and everyone in the room has it. |
| 0:45 | **Share a reel live** from Instagram → ReelBrain. Show the pipeline stages ticking. |
| 1:30 | While it runs: open the map. 25 pins across Kerala and Tamil Nadu. *"This is a month of saved reels."* |
| 2:15 | Open a **Malayalam** reel. Toggle Malayalam → English → Manglish. |
| 3:00 | **The money shot.** Open a comment-only reel. *"This creator never says where it is. Not in the audio, not in the caption."* Then show the evidence panel — the creator's reply, quoted. *"We read the comments for you."* |
| 4:00 | Search: *"that spicy beef place near the beach"*. Right reel, first result. |
| 4:45 | Location simulator → walk near a saved spot → notification → Directions. |
| 5:15 | The six-vertical slide. *"Food Spot is one JSON schema. Jobs, recipes, travel, products, events are the same pipeline."* |
| 5:45 | Close: *"Your saved folder is a graveyard. We're making it a second brain."* |

---

## Cut list (in order, when you run out of time)

1. Dark mode
2. Product-comparison vertical
3. Category chips / faceting
4. Confirm cards → auto-accept top Places candidate (keep the evidence panel!)
5. Trigram/Manglish search arm → semantic + keyword only
6. Map clustering → plain markers

**Never cut:** comment mining, the evidence panel, the multi-language transcript toggle.
Those three *are* the pitch.
